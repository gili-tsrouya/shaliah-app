# משפחות מתודות (המסע בצופים)

The method families Gili works with, from the Tzofim "המסע בצופים" material she provided. Every method in an
activity belongs to exactly one family. Use the family names exactly as written here.

| משפחה | מה זה, בדוגמאות |
|---|---|
| משחק תחרות | מירוץ שליחים, חידון, הדגל, משימה בקבוצות |
| עשייה | יצירת מפה של השכונה, מפגש עם קבוצה שונה, בניית תקנון, פרמידה אנושית |
| ייצוג | בחירת ציטוט / תמונה / טקסט וכו׳, סולם מסכים – לא מסכים |
| הבעה יצירתית | כתיבת שיר, יצירת קולאז׳, הצגה, תרגיל התרחשות |
| השראה | עבודה עם טקסט, מפגש עם אדם מעורר השראה, צפייה בסרט / הרצאה, סיור במקום או בפרויקט |
| דיון בשאלה | החלפת דעות, משפט מבוים, יצירת פרובוקציה |
| חשיבה משותפת | סיעור מוחות, כתיבת סיפור בהמשכים ביחד, פיתוח רעיונות לפרויקט |
| שיתוף | מעגל הקשבה, סיפור אישי, פינת החניך (מספר משהו שקרה לו השבוע) |
| משחק הדמייה | משחק תפקידים, תרגילי תיאטרון, בית משפט |
| התבוננות | צפייה מהצד על פעילות, סיור בחינת השכונה, הסתכלות על עצמי |
| הסבר | מילולי, בציור, על ידי חפצים, דוגמאות מהשטח |
| פירוק | מחקר בסוגיה, ממה מורכב המצב בארץ?, יצירת תרשים |

## How to build an activity from them
- 3 to 5 methods, about 45–60 minutes in total (younger groups: shorter methods, more movement).
- Open with something that gets everyone in (often ייצוג, משחק תחרות, שיתוף or השראה), put the core in the middle
  (דיון בשאלה, משחק הדמייה, פירוק, חשיבה משותפת, עשייה), and close with something personal or shared
  (שיתוף, הבעה יצירתית, ייצוג).
- Use at least 3 different families in one activity, and never two of the same family back to back.
- Every method says why it is there (`purpose`), what exactly happens (`content`), how long it takes and what to bring.
